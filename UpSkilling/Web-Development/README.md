# Local Community Event Portal

A simple web-based Local Community Event Portal developed using HTML5, CSS3, and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery

## Features

- Navigation between different sections
- Welcome banner
- Upcoming events
- Event search and category filtering
- Event registration form
- Form validation
- Event gallery
- Event video
- Feedback section
- Character counter
- Local Storage and Session Storage
- Geolocation
- Fetch API
- Responsive design
- Community news section
